## 推荐做法：装一次，以后免维护

每次改汉化都要重新下载、手动替换文件，太麻烦。所以做了个自动更新插件——**装一次，之后版本更新它自己处理。**

**1.** 下载本仓库根目录的 **`CU_TransUpdater.dll`**

**2.** 确认已安装 **BepInEx 5.x（Mono）**（装过社区汉化的通常都有了）

**3.** 把 DLL 放进 `游戏根目录\BepInEx\plugins\`

**4.** 启动游戏，完事

之后每次启动，它会去本仓库读 `latest.json`，发现新版本就自动下载并写进 `Lang` 目录。

- 下载后核对 SHA256，对不上就拒绝写入，不会给你塞半个文件
- 旧文件留一份 `.bak`，出问题能退回去
- 网络不通只跳过，不影响游戏启动
- 只写 `tigerLin CustomTrans.json` 这一个固定文件名，不会动你 `Lang` 里的其它文件

**主菜单左下角**会出现一个小徽标（`TRANS` + 版本号），点一下展开：当前版本 / 远端版本 / 上次检查 / 状态，还能手动「立即检查」。**游戏内不会显示任何东西。**

配置在 `BepInEx\config\com.tigerlin.cu.transupdater.cfg`，可改检查间隔、超时、界面语言、徽标位置。

<details>
<summary><b>不想装插件？手动下载也可以（点开）</b></summary>

下载本仓库的汉化 JSON，拖进 `游戏根目录\CasualtiesUnknown_Data\Lang` 即可。

缺点：每次更新都要重来一遍，而且要自己判断哪个是最新版。

</details>

## 这是什么

这是《Casualties Unknown》的一款个人定制版简体中文本地化。

英文原文是冷静的说明书。准确，详尽，但不负责教你活下去。你得自己试过才知道它真的会杀了你。

游戏已有的那份社区精准翻译严谨、忠实、克制，


本版本不试图取代它，**而是走另一条路：**

本版本是一份**活下来的队友写的笔记**。不一定每个词都对应原文，但会告诉你「这一步可能死」。

“不忠实”的翻译不等于劣质的翻译。这里的「不忠实」是故意的，是设计选择。

## 本版本做了什么

**硬核医疗，软性讲解**

游戏拥有极其复杂的医疗系统（骨折、出血、感染、截肢、阿片类药物过量……）。

本翻译尽量把每种药品的实际用途、风险和注意事项讲得通俗易懂，而不是照搬原文

简而言之

**不需要自己试错才知道什么会要命**

**重建了信息层级**

- 红色：致命警告，认真看
- 黄色：实用提示，建议看
- 橙色：轻松吐槽，随便看
- 灰色：彩蛋

**给了游戏一个叙事声音。**

原版像监控摄像头：客观，有距离。本版本像一个跟你一起被扔进洞穴的倒霉蛋在物品上贴的便条————懂的不一定多，但吃过亏是真的。

**中文互联网语境**

部分描述使用了中文网络文化中的表达。如果你看到看不懂的梗可以去去B站补课。

## 常见问题

**Q: 为什么叫「不那么忠于原文」？这不是翻译错误吗？**

不是错误，是设计。本版本的核心理念是在理解原文含义的基础上，用中文玩家更亲切、更好记的方式表达。如果你追求每个词都严格对应原文，社区精准版更适合你。

**Q: 里面的梗会不会过时？**

会。网络梗有保质期，这是本版本的一部分。把它当作2026年的时代胶囊，而不是永恒文本。

后期如果有机会的话会尽量更新

**Q: 多人模式能用吗？**

能，经由我和我朋友亲自测试。如果你在多人模式中使用而出现Bug了，欢迎反馈。

**Q: 发现有翻译问题或想提建议？**

去B站找 @_tigerLin_ 反馈，提 Issue 嘛...我好像不常上GitHub，因此随缘回复

另外，迫于学业压力，仅周末可以回复

**Q: 什么时候出V1.0.0？**

游戏正式版在 2026-11-09 发了，现在这版（V0.5.0）就是适配正式版的版本，先让大家有得用。

V1.0.0 嘛……等我慢慢把新增的两万多字啃完再说吧。
